**DeepseekExtractor** — утилита для извлечения чатов из истории переписки DeepSeek. Является подключаемым плагином для программного комплекса [Pyrog](https://ironmesh.ru/ru/products/22-prilozheniya/71-pyrog).

Руководство по установке и использованию читайте в [материале](https://wiki.ironmesh.ru/products:pyrog-plugins:deepseek-extractor:manual:main).

**Основные функции и особенности утилиты:**

* Импорт истории переписки DeepSeek в формате JSON
* Экспорт выбранных чатов в нативный формат Deepseek
* Извлечение требуемой ветки сообщений из чата
* Расчет количества токенов, слов и символов в выбранной ветке сообщений
* Преобразование ветки сообщений в требуемый формат (Обычный текст, Markdown, HTML4) и сохранение на диске
* Возможность написать собственные представления для вывода ветки сообщений
* Открытый исходный код
* Интерфейс на русском и английском языках
