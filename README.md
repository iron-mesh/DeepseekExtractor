**DeepseekExtractor** is a utility for extracting chats from the DeepSeek chat history. It is a plug‑in for the [Pyrog](https://translate.google.com/translate?sl=ru&tl=en&u=https://ironmesh.ru/ru/products/22-prilozheniya/71-pyrog) software suite.

Read the installation and usage guide in the [Material](https://translate.google.com/translate?sl=ru&tl=en&u=https://wiki.ironmesh.ru/products:pyrog-plugins:deepseek-extractor:manual:main).

**Main features of the utility:**

* Importing DeepSeek chat history in JSON format
* Exporting selected chats to the native Deepseek format
* Extracting the required message thread from a chat
* Calculating amount of tokens, words and characters in the message thread
* Converting the message thread to the required format (Plain text, Markdown, HTML4) and saving it to disk
* The ability to develope custom views for displaying the message thread
* Open source code
* Interface in Russian and English
